# Linux-Hardening-Auditing

This Bash script is a high-performance Linux auditing and remediation suite built for speed and reliability. It uses compiled C helpers to deliver real POSIX threading and forking, making system-wide security scans significantly faster than standard scripts. 

The tool hunts for SUID vulnerabilities, audits system configs, and creates file baselines to detect unauthorized "drift". It includes a safe auto-remediation engine to fix identified holes and can export results to JSON for reporting.
